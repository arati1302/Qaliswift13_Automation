# Orange HRM PIM Tests

This project contains Playwright tests for the PIM module in Orange HRM application.

## Setup

Install dependencies:

```bash
npm install
```

Set environment variable:

- `BASE_URL`: The base URL of the deployed Orange HRM staging environment.

## Running tests

To execute the tests:

```bash
npx playwright test
```

Test reports and failure screenshots/videos/traces will be saved automatically.
